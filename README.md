# LottoBot — บอทส่วนตัวดึงผลหวยให้ LottoSnap

ใช้ Python 3.9+ เท่านั้น ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้องเช่า API รายเดือน
บอทดึงผลมาเก็บเป็นไฟล์ JSON ใน `site/` แล้วคุณโฮสต์ไฟล์เหล่านั้นฟรี (GitHub Pages ฯลฯ)

## เริ่มใช้ใน 5 นาที (ทดลองบนเครื่อง)

```bash
python bot.py selftest        # ทดสอบตรรกะภายใน ต้องขึ้น "ผ่านทั้งหมด"
python bot.py probe           # ลองต่อแหล่งข้อมูลจริง + เก็บหน้าดิบไว้ใน probe_out/
python bot.py fetch           # ดึงผล → site/
python bot.py serve           # เสิร์ฟ site/ ที่ http://localhost:8787
```

แล้วเปิด LottoSnap → ตั้งค่า → "แหล่งข้อมูลหวยไทย (API)" ใส่ `http://localhost:8787`

## สถานะแหล่งข้อมูล (อ่านก่อน)

| ชนิด | วิธีดึง | สถานะ |
|---|---|---|
| หวยรัฐบาลไทย | ชุดข้อมูลชุมชน [huayreview/thai-lottery-results](https://github.com/huayreview/thai-lottery-results) (CC BY 4.0) เป็นหลัก + endpoint ของ สลก. สำหรับงวดที่ชุดข้อมูลยังไม่มี | สคีมาตามเอกสารของชุดข้อมูล แต่**ยังไม่เคยดึงไฟล์จริงจากเครื่องผม** (URL ในโค้ดอนุมานจากชื่อไฟล์) และ endpoint ของ สลก. ยังไม่ได้ยืนยัน — รัน `probe` ก่อนเสมอ |
| ธ.ก.ส. / ลาว / ฮานอย / มาเลย์ | ดึงหน้าเว็บ + regex ที่คุณตั้งใน `sources.json` | ปิดอยู่ (ไม่มี url) — ต้องเลือกเว็บที่คุณไว้ใจแล้วปรับ regex ด้วย `probe` |
| ยี่กี | ไม่มีแหล่งกลาง | กรอกด้วยคำสั่ง `add` |

บอทตรวจความถูกต้องก่อนเผยแพร่เสมอ (หวยไทยต้องมีครบทุกรางวัลและตัวเลขครบหลัก) ถ้าเว็บเปลี่ยนโครงหน้า
บอทจะ **ไม่เขียนข้อมูลเสีย** แต่จะจบด้วย exit code 1 (บน GitHub Actions คุณจะได้อีเมลแจ้ง)

ตัวแปรเสริม: `DATASET_URL=` ชี้ไปที่ไฟล์ชุดข้อมูลที่คุณ mirror ไว้เอง, `THAI_FALLBACK_BASE=` เป็น API สาธารณะรูปแบบ rayriffy (หมายเหตุ: โดเมน lotto.api.rayriffy.com เลิกให้บริการแล้ว)

ชุดข้อมูลชุมชนอาจล่าช้ากว่าประกาศจริงหลายวัน และต้องให้เครดิตตามสัญญาอนุญาต CC BY 4.0 (แอปใส่ไว้ในหน้า About แล้ว)

## เปิดแหล่งหวยอีก 4 ชนิด

1. ใส่ `"url"` ของหน้าผลรางวัล + `"enabled": true` ใน `sources.json`
2. `python bot.py probe` → เปิด `probe_out/<ชนิด>.txt` (ข้อความที่บอทเห็น)
3. ปรับ `anchor` (ตัดข้อความก่อนผลล่าสุด) และ `regex` (named groups ตามหมายเหตุในไฟล์) จน probe ขึ้น ✔
4. `date_regex` (กลุ่ม d, m, y) ถ้าหน้าเว็บมีวันที่ — ถ้าไม่ตั้ง ป้ายงวดจะเป็น "ดึงเมื่อ …" ซึ่งอาจเป็นผลของงวดก่อนหน้าได้ ถ้าเว็บยังไม่อัปเดต

เช็กเงื่อนไขการใช้งาน/robots.txt ของเว็บที่เลือกเอง ดึงถี่แค่เท่าที่จำเป็น (ค่าเริ่มต้นของ workflow คือวันละไม่กี่ครั้ง)

## ดึงผลทันทีที่หวยออก (โหมด watch)

```bash
python bot.py watch --out site        # รันค้างไว้ (เครื่องส่วนตัว/Raspberry Pi/VPS เล็ก ๆ)
NOTIFY_WEBHOOK=https://discord.com/api/webhooks/... python bot.py watch   # แจ้งเตือนเมื่อมีผลใหม่/ดึงไม่ได้
```

- ฮานอย / มาเลย์ 4D / ลาว ใช้ตัวอ่านอิง "รูปแบบตัวเลขของผลรางวัล" (`scrapers.py`) ไม่ใช่ CSS selector — เว็บเปลี่ยนดีไซน์ก็ยังอ่านได้ ตราบใดที่ตัวเลขยังอยู่ใน HTML
- ใน `sources.json` ใส่หลาย URL ใน `sources` + `quorum` (เช่น 2): บอทจะบันทึกก็ต่อเมื่อ ≥ quorum แหล่งให้ผลตรงกัน
- `schedule` (เวลาไทย) ให้บอทดึงเฉพาะช่วงที่หวยออก ถี่ตาม `poll_seconds` (ขั้นต่ำ 20 วิ) ถอยห่างอัตโนมัติเมื่อล้มเหลว และหยุดเมื่อได้ผลของวันนั้นแล้ว
- ถ้าเจอ Cloudflare/captcha/403/429 บอท**ไม่พยายามหลบเลี่ยง** — จะขึ้น "ถูกบล็อก" และแจ้ง webhook ให้คุณเปลี่ยนแหล่ง หรือขออนุญาต/ใช้ฟีดทางการของเว็บนั้น
- หน้าที่สร้างผลด้วย JavaScript: ตั้ง `"render":"browser"` (ต้อง `pip install playwright && playwright install chromium`)
- ข้อจำกัด: selftest ใช้หน้าเว็บจำลอง ยังไม่เคยทดสอบกับเว็บจริงจากเครื่องผม — รัน `python bot.py probe` กับ URL ของคุณก่อนเปิดใช้ และเปิด `probe_out/*.txt` ดูข้อความที่บอทเห็น (ใช้ `anchor`/`stop`/`exclude` ตัดส่วนที่ไม่เกี่ยวข้อง เช่น ผลงวดก่อน/โฆษณา)
- GitHub Actions cron ไม่ใช่ "ทันที" (ห่างสุด ~20 นาที + อาจล่าช้า) ถ้าต้องการเร็วจริงให้รัน `watch` บนเครื่องที่เปิดตลอด

### ธ.ก.ส. (`parser: gsb`)
อ่านจากหน้าทางการ `https://www.baac.or.th/lottery-results` ตามป้ายรางวัล (รางวัลที่ 1 = 7 หลัก, เลขท้าย 4/3/2 ตัว) และข้ามส่วนสลากดิจิทัล ถ้าหน้าไม่แสดงเลขท้าย 2 ตัว บอทจะไม่สร้างรางวัลนั้น (ไม่เดา)

## ให้แอปดึงผลจากเว็บได้เองโดยไม่ต้องรันบอท (พร็อกซีฟรี)

เบราว์เซอร์อ่านเว็บอื่นตรง ๆ ไม่ได้ (CORS) — แอปจึงผ่านพร็อกซี ทางที่เสถียรคือ Cloudflare Worker ของคุณเอง (ฟรี ไม่ต้องมีเซิร์ฟเวอร์):
1. dash.cloudflare.com → Workers & Pages → Create → Hello World → Edit code → วางไฟล์ `cf-worker.js` → Deploy
2. คัดลอก URL (เช่น `https://lottosnap-proxy.ชื่อคุณ.workers.dev`) ไปใส่ในแอป ตั้งค่า → ดึงผลจากเว็บโดยตรง เป็น `https://lottosnap-proxy.ชื่อคุณ.workers.dev/?url={url}`
3. อนุญาตเฉพาะโดเมนในตัวแปร `ALLOW` (xosominhngoc.com, lottery.kapook.com, baac.or.th) และเฉพาะ GET

แอปดึงได้: ฮานอย (ผล + ย้อนหลัง), ลาว (kapook ผล + ย้อนหลัง), ธ.ก.ส. (หน้าทางการ ล่าสุด) — หวยมาเลย์ยังไม่มีเว็บที่ดึงแบบนี้ได้

## ผลย้อนหลังของ ธ.ก.ส. / ลาว / ฮานอย / มาเลย์

บอทเก็บผลทุกงวดที่ดึงได้ไว้ที่ `site/other/<ชนิด>-history` แอปจะโหลดไปรวมในหน้า "ตรวจงวดย้อนหลัง" และหน้าสถิติเอง
- **สะสมต่อจากนี้** — ใช้ได้กับทุกชนิดทันที (ทุกครั้งที่ `fetch`/`watch` ได้ผลใหม่ที่มีวันที่)
- **ดึงย้อนหลังทีเดียว** — ทำได้เฉพาะเว็บที่มีหน้าแยกตามวันที่ ตั้ง `history_url` ใน `sources.json` แล้วรัน
  `python bot.py backfill hanoi --days 60` (หน่วง 2 วินาทีต่อหน้า หยุดทันทีถ้าถูกบล็อก)
  ตั้งไว้ให้เฉพาะฮานอย (Minh Ngọc รองรับ `.../mien-bac/DD-MM-YYYY.html` ตามที่ผมเปิดดูได้ แต่ยังไม่ได้ทดลองรันบอทกับเว็บจริง)
- ชนิดอื่นที่ผมยังไม่พบหน้าย้อนหลังที่ใช้ได้ ใช้ `python bot.py add <ชนิด> --date 2026-10-16 ...` กรอกย้อนหลังเองได้ ผลจะเข้า history ให้

## กรอกเองด้วยคำสั่ง (ใช้ได้ทุกชนิด ไม่พึ่งเว็บ)

```bash
python bot.py add lao    --n4 4036
python bot.py add hanoi  --special 12345 --first 67890
python bot.py add yeekee --top3 123 --bottom2 45 --round 7
python bot.py add my     --numbers "1111 2222 3333 ... (รวม 23 เลข)"
python bot.py add gsb    --first 1234567 --last3 123 --last2 45
```

บอทสร้างรางวัลให้เอง เช่น ลาว 4036 → 4 ตัวตรง 4036 / 3 ตัวบน 036 / 2 ตัวบน 36 / 2 ตัวล่าง 40

## โฮสต์ฟรีด้วย GitHub Pages + Actions

1. สร้าง repo ใหม่ แล้วอัปโหลดทั้งโฟลเดอร์นี้ (รวม `.github/`)
2. Settings → Pages → Source: **GitHub Actions**
3. Actions → lottobot → Run workflow (ครั้งแรก) — ถ้าต้องการย้อนหลัง รัน `python bot.py fetch --backfill-months 24` บนเครื่องแล้ว commit โฟลเดอร์ `site/`
4. URL ที่ได้ (`https://<user>.github.io/<repo>`) คือค่าที่ใส่ในแอป

ข้อควรรู้: cron ของ GitHub อาจล่าช้าได้หลายนาที และ repo ที่ไม่มีกิจกรรม 60 วันอาจถูกปิด schedule — ตรวจดูเป็นระยะ
ทางเลือกอื่น: รัน `python bot.py fetch` ด้วย cron บนเครื่อง/Raspberry Pi/VPS เล็ก ๆ แล้วเสิร์ฟ `site/` ด้วย Nginx หรือ Cloudflare Pages

## ติดตั้งบอทบน GitHub (แนะนำ: repo แยกชื่อ lottobot)

1. สร้าง repo ใหม่ชื่อ `lottobot` (Public) แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด **รวมโฟลเดอร์ `.github`** (โฟลเดอร์ที่ขึ้นต้นด้วยจุดบางทีไม่ติดมาตอนลาก — ให้เช็กว่ามี `.github/workflows/lottobot.yml` ใน repo)
2. Settings → Actions → General → Workflow permissions → เลือก **Read and write permissions** → Save
3. Settings → Pages → Source → **GitHub Actions**
4. แท็บ Actions → lottobot → **Run workflow** (ครั้งแรก) รอให้ขึ้นเครื่องหมายถูกสีเขียว
5. ได้ URL `https://<ชื่อผู้ใช้>.github.io/lottobot` → ใส่ในแอป ตั้งค่า → "แหล่งข้อมูลหวยไทย (API)" (GitHub Pages เปิด CORS ให้อยู่แล้ว ไม่ต้องใช้พร็อกซี)
- ถ้า step ไหนขึ้นสีแดง กดเข้าไปดู log ได้ว่าเว็บต้นทางบล็อก/โครงหน้าเปลี่ยน — บอทไม่เขียนข้อมูลเสีย
- ย้อนหลังเริ่มต้น: Actions → Run workflow ไม่ได้ย้อนไกล ให้รันบนเครื่อง `python bot.py backfill hanoi --days 60` แล้วอัปโหลดโฟลเดอร์ `site/` ขึ้น repo

## โครงไฟล์ที่บอทสร้าง

```
site/latest              หวยไทยงวดล่าสุด (รูปแบบ rayriffy)
site/list/1,2,…          รายการงวด หน้าละ 10 (หน้าสุดท้ายว่าง)
site/lotto/YYYY-MM-DD    ผลแต่ละงวด
site/other/<ชนิด>        ผลล่าสุดของ gsb|lao|hanoi|my|yeekee
site/index.json          สรุปสถานะ
```

LottoSnap ใช้เพื่อตรวจผลรางวัลเท่านั้น ไม่เกี่ยวข้องกับการซื้อขายหรือพนัน
